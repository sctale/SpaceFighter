# 太空战斗机 · Aurora Rift

一款纯前端、竖屏、单局 3–8 分钟的霓虹深空街机弹幕射击游戏。HTML5 Canvas 负责全部玩法与程序化美术，Capacitor 封装为 Android 应用。

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](./LICENSE)

> 穿过裂隙，在弹幕之间起舞。

## 玩法特性

- **12 种敌机**：普通机群、俯冲蜂、扇形射手、环状炮台、分裂体、重装堡垒、陨石、长炮狙击、布雷者、侧掠弯刀、召唤母舰与分裂幼体；每种都有独立轮廓、移动轨迹与开火方式
- **22 种 Boss 招式**：三台 Boss 各自拥有 3 套按阶段编排的招式序列（固定顺序循环，可背板），阶段切换清空弹幕并给出喘息窗口，血量低于 12% 进入「临界」不再停顿
- **3 条武器线 × 5 级**：脉冲阵列（最快最轻）、棱镜贯穿（最慢最重）、蜂群追踪（中速中威力）；等级永久保留、可手动切换，受伤只掉当前武器一级
- **蓄能换线**：每条线开火持续消耗蓄能，打空即「失谐」（威力 55%、射速下降），换线待机回充——想一直用一把武器是不可能的
- **共鸣连携**：换到蓄能健康的武器线叠共鸣，每层 +8% 伤害最多 5 层，停手不换会逐层衰减
- **舰体换色**：脉冲青 / 棱镜玫红 / 蜂群金，机身、尾焰、弹道拖尾与护盾环整体跟随当前武器线
- **主机与僚机弹道分离**：僚机弹药形态跟随当前武器线（高速细弹 / 低速重击 / 弧线寻的弹），僚机类型决定火力密度与瞄准方式
- **4 类僚机 · 翼位编队**：固定停在左翼、右翼与尾部挂载点，跟随带阻尼而不绕圈，最多编队 3 架；机体被击中时僚机会爆炸失联，只能靠拾取补回
- **护盾与力场**：护盾最多叠 3 层，开局自带 1 层；棱镜力场可在 8 秒内吞噬附近弹幕并抵消一次致命伤害
- **出场公平性**：敌机未合法进入画面前不可被锁定、不可受伤害，追踪弹另有锁定延迟与转向上限
- **擦弹与连锁**：贴近弹幕积攒星爆，连续击落提升倍率；星爆还会随时间自然回复，命中敌机/Boss 与被击中都有充能补偿（掉命 +25）；冲刺拥有短暂无敌帧
- **星区推进**：10 个命名星区循环，敌机数量、弹速、血量与 Boss 强度逐步提升
- **本地优先**：无账号、无服务器、无网络请求；最高分、最远星区与设置仅存在 `localStorage`

## 操作

| 输入 | 动作 |
| --- | --- |
| 拖动 / 鼠标 | 驾驶战机，自动开火 |
| 方向键 / WASD | 键盘移动 |
| `Q` / `E` / `F` · 点击武器卡 | 循环切换已解锁武器线 |
| `1` `2` `3` | 直选脉冲 / 棱镜 / 蜂群 |
| `SPACE` / 冲刺按钮 | 冲刺穿越弹幕 |
| `X` / 星爆按钮 | 清空弹幕并进入超频 |
| `ESC` / 暂停按钮 | 暂停与设置 |
| 贴近敌弹 | 擦弹积攒 NOVA |

## 技术栈

- 原生 JavaScript + HTML5 Canvas 2D，无游戏引擎
- 程序化矢量美术、预渲染精灵与粒子系统
- Web Audio API 合成音乐与音效
- Capacitor 8 封装 Android WebView
- Playwright + Edge 做视觉、交互与压力回归

## 快速开始

要求 Node.js 20+。

```bash
npm install
npx cap sync android
```

### 浏览器直接游玩

用任意静态服务器打开 `www/`：

```bash
npx serve www
```

然后访问终端显示的地址。也可以直接双击 `www/index.html` 进行基础试玩；音频需要一次点击解锁。

### Android 调试包

```bash
npx cap open android
```

在 Android Studio 中运行，或使用：

```bash
cd android
./gradlew assembleDebug
```

### 本地 Release APK

```bash
cd android
./gradlew assembleRelease
```

产物位于：

```text
android/app/build/outputs/apk/release/app-release.apk
```

当前仓库的 release 配置使用 debug 签名，方便本地安装与开源验证；正式上架前请替换为自己的 keystore，并妥善保管。

## 测试

```bash
npm test              # 冒烟 + 90 秒跨星区压力模拟 + 帧率
npm run test:design   # 玩法设计回归（见下）
npm run test:all      # 两者一起跑
```

`npm test` 会启动 Edge headless，完成：

- 菜单、战斗、暂停、结算与触控流程
- 12 种敌机和 Boss 招式采样
- 武器模式、僚机、护盾与力场逻辑
- 90 秒跨星区压力模拟、NaN 检测与帧率检查
- 360×640、390×844、1440×900 响应式截图

`npm run test:design` 用同一份游戏对象做数值回归，25 项断言：

- 僚机是否停在左右翼位（不绕圈）
- 主机弹与僚机弹的弹种是否互不重叠
- 未进入画面的敌机是否无法被锁定与伤害
- 弹速三角（脉冲 > 蜂群 > 棱镜）与单发威力三角（棱镜 > 蜂群 > 脉冲）
- 蓄能是否按预期打空并进入「失谐」，换线后是否回充
- 换线是否叠共鸣增伤，被击中是否同时损失蓄能、共鸣与一架僚机
- 僚机弹药形态是否跟随武器线，舰体是否换色
- 失谐武器是否降低 NOVA 充能效率
- 星爆是否以环形进度充能、旧版悬浮卡片是否移除、战机是否不进底部仪表带
- 三条武器线在 LV.1/3/5 的实测 DPS，以及等级倍率与武器间差距
- 22 种 Boss 招式是否各自真的开火
- 阶段招式序列是否固定、阶段切换是否清屏、弹幕压力是否逐阶段上升
- 「临界」过载是否触发
- 新手 / 中期 / 满配三种构筑下 Boss 战时长是否落在设计区间
- 站着不躲的船在阶段三能否被持续击落

测试截图默认输出到 `.tools/shots/`，该目录不进入版本库。

## 目录结构

```text
www/
  index.html          HUD、菜单、暂停与结算界面
  css/game.css        设计令牌与界面样式
  js/core.js          工具、输入、程序化音频
  js/art.js           飞船、敌机、Boss、拾取物与精灵缓存
  js/background.js    星云、极光、星域与菜单场景
  js/entities.js      玩家、敌机、Boss、子弹、护盾、僚机
  js/director.js      星区波次编排
  js/ui.js            HUD 与屏幕状态
  js/game.js          状态机、碰撞、粒子与主循环
android/              Capacitor Android 工程
.tools/               视觉与回归测试脚本
legacy/               v1.0 单文件旧版存档
```

## 发布

版本号和更新说明以 `CHANGELOG.md` 为准。构建 APK 后，按项目约定将产物上传到 GitHub Release，不把大体积安装包提交进 Git。

```bash
gh release create v2.2.0 \
  --title "v2.2.0" \
  --notes-file release-notes.md \
  SpaceFighter-v2.2.0.apk
```
